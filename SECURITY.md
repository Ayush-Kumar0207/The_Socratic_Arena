# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or debate room.

Report them privately through the repository's [GitHub Security Advisories](https://github.com/Ayush-Kumar0207/The_Socratic_Arena/security/advisories/new). Include the affected URL or component, reproduction steps, impact, and any suggested mitigation. Remove secrets and personal data from screenshots or logs.

We will acknowledge a complete report as soon as practical, investigate it, and coordinate disclosure after a fix is available. Public-beta service levels do not include a guaranteed response time or bug-bounty payment.

## Supported version

Security fixes target the current production deployment and the latest commit on `main`. Older commits and self-hosted modifications are not maintained by the project team.

## Scope reminders

- Never submit live credentials, tokens, or private user data as test evidence.
- Use accounts and content you are authorized to test.
- Avoid denial-of-service testing against the public deployment.
- AI output and evidence matches are advisory; do not treat them as verified facts without human review.
